# Kolhapuri Fashion Saree — Premium Handloom E-Commerce Platform

A production-ready e-commerce platform and owner administration dashboard for **Kolhapuri Fashion Saree**, celebrating authentic royal Paithani, Kanjivaram, and Banarasi handloom weaves crafted in Kolhapur, Maharashtra.

## Key Features

### 🛍️ Customer Experience
- **Announcement Bar**: Dynamic rotating promotional messages managed from the owner portal.
- **Top Navigation**: Clean 3-zone layout with brand wordmark, live search, wishlist counter, shopping bag drawer, and email OTP sign-in.
- **Hero Carousel**: Automatic rotating promotional carousel featuring authentic editorial Paithani and bridal silk photography.
- **Circular Categories**: Silk, Paithani, Traditional, Designer, Festive, Wedding, Cotton, and Party Wear sarees.
- **Product Catalog**: Live search, category filtering, fabric filter, and sorting (Newest, Price, Popularity, Discounts).
- **Product Details Page (PDP)**: Multi-angle photography gallery, border and pallu close-up, color swatches with individual stock, fabric specifications, blouse piece details, and care instructions.
- **Wishlist & Cart**: Persistent shopping bag, live subtotal, coupon code application (`FESTIVE10`, `KOLHAPUR20`), and free delivery threshold calculations.
- **Multi-Step Checkout**: Customer email OTP verification, delivery address book, order summary, and sandbox Razorpay payment simulation with instant signature verification.
- **Customer Order Tracking**: Real-time status progression (Order Confirmed → Processing → Packed → Shipped → Out for Delivery → Delivered) with Blue Dart tracking links and pre-dispatch cancellation.

### 🛡️ Owner Admin Dashboard
- **Executive KPIs**: Real-time gross sales, confirmed paid revenue, total orders, processing orders, and weaver restocking alerts.
- **Saree Product Management**: Add and edit sarees, manage SKU, original price, selling price, fabric, occasion, and variant color swatches.
- **Inventory & Reservations**: Transactional stock reservation on checkout initiation, manual stock adjustments with audit reasons, and complete movement logs.
- **Order & Shipment Fulfillment**: State machine status updater, Blue Dart / Delhivery tracking number assignment, and authorized refund workflow.
- **Promotions & Offers**: Create and manage coupons with usage limits and minimum order values.
- **Store Policies**: Configure announcement messages, business phone (`9096863092`), WhatsApp link, Instagram handle (`@ankita_wavecode`), and address (`Shivaji Nagar, Unchgaon, Kolhapur, Maharashtra`).
- **Security Audit Logs**: Chronological log of administrative actions.
